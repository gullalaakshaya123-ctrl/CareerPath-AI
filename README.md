# 🎯 CareerPath AI

### Your Agentic AI Career & Employment Assistant

CareerPath AI is a multi-agent AI career guidance application designed to help students and early-career youth make better career decisions.

It analyzes a user's education, current skills, target career, graduation year, and preferred location to provide personalized career guidance, skill-gap analysis, learning recommendations, portfolio project ideas, and internship/job preparation guidance.

---

## 🚀 Features

- 🎯 Personalized career suitability analysis
- 🧠 AI-powered skill-gap analysis
- 📚 Recommended skills for the target career
- 🗓️ Personalized 30-day learning roadmap
- 🛠️ Portfolio project recommendations
- 📄 Resume analysis and improvement guidance
- 💼 Internship and entry-level job preparation
- 📍 Location-aware career guidance
- 🤖 Multi-agent AI workflow
- 📥 Downloadable personalized career report

---

## 🤖 Multi-Agent Architecture

CareerPath AI uses multiple specialized AI agents to analyze different aspects of a user's career profile.

### Career Agent
Analyzes the user's education, skills, target career, and profile to provide career suitability insights.

### Skill Gap Agent
Identifies missing or underdeveloped skills required for the user's target career and recommends skills to learn.

### Resume Agent
Provides resume-related guidance and suggestions for improving the user's professional profile.

### Opportunity Agent
Provides guidance related to internships, entry-level opportunities, and career preparation.

The agents work together to produce a personalized career action plan.
